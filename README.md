# Proxima Wiki — MkDocs Material

## Come pubblicarla su GitHub Pages

1. Svuota o sostituisci i file del repository `proxima-wiki` con il contenuto di questa cartella.
2. Fai commit su `main`.
3. Vai su `Settings → Pages`.
4. In `Build and deployment`, seleziona:
   - Source: `Deploy from a branch`
   - Branch: `gh-pages`
   - Folder: `/ (root)`
5. Vai su `Actions` e aspetta che il deploy diventi verde.

## Modifiche normali

Modifica i file dentro `docs/`:

- `docs/index.md`
- `docs/lore/impero.md`
- `docs/lore/pantheon.md`
- `docs/storia/piaga-del-fuoco.md`
